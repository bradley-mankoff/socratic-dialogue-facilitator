# Ponytail audit: socratic-dialogue-facilitator

This file lists over-engineering in the socratic-dialogue-facilitator repository, a standard-library-only Python project with the packages `board/`, `dictionary/`, `search/`, `server/` and `tests/`. It follows the ponytail-audit skill (`~/.claude/skills/ponytail-audit/SKILL.md`): each finding names what to cut, what replaces it, and where it lives, ranked biggest cut first. The audit changes no code; it only lists findings.

An Opus 5.5 session wrote the first version on 2026-10-05. A review session on 2026-10-11 re-checked every claim against the working tree at commit 4184605 and rewrote the list. The review corrected wrong counts, callers and test impact; each item that changed says what the first version claimed. It also added one cut (item 8: `from_dict` methods that nothing calls) and dropped two claims (see "Checked and not listed"). Every caller claim below comes from `rg` over the tree. Import claims were also checked with a scan of import statements using Python's `ast` module. All line numbers refer to commit 4184605.

## Why the excess exists

Most of the excess has one cause. The factory's forced-fuse judge prompt, `.archon/commands/fusion-judge-impl-fuse-forced.md:8`, says "Synthesize them. Do not merely pick one." Each judge therefore kept every panel's function names and fields so that every panel's tests would still pass. The code says so in its own docstrings, for example `board/machine.py:110-118` and `dictionary/model.py:3-21`.

In the four packages' `.py` files, 175 lines match the pattern `fused|Fused|panel-[abc]|Panel-[abc]|panel [abc]`. Seven of those are false hits on the words "refused" and "confused". The other 168 are prose: 117 docstring lines and 51 `#` comment lines, classified with Python's `tokenize` and `ast` modules. No executable line names a panel. The `README.md` files in `dictionary/` and `search/` add 8 more matching lines.

The prompt lives in `.archon/`, which the software-factory project owns; its `projectify.py` (now at `~/Developer/archive/software-factory/projectify.py:42-48`) copies the command prompts into this repository. This audit does not touch `.archon/`. While `factory.json:4` sets `default_tactic` to `fusion-02` and the prompt stays as it is, each fusion ticket can add the same kind of layer.

## How the line counts were measured

Each item's cut was counted from the line ranges it cites, including the blank lines that separate a deleted definition. The count subtracts an estimate of the lines the replacement adds. Docstring and comment prose inside files that stay was not counted, so the real cut is somewhat larger. Whole-file deletions count every line of the file. The source total is 2,303 lines. The test total is about 484 lines: 468 from item 1, about 12 from item 16 and about 4 from item 19. The other items' test edits replace one line with one line. Treat each number as accurate to within about 5 percent.
