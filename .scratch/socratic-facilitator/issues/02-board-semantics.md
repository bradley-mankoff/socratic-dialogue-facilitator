# 02 — Board semantics for single toggleable board

Type: grilling
Status: resolved
Blocked by: none

## Question

Lock the board model for one board that toggles async/live freely: canonical defs vs claimed defs vs single active definition under elenchus, counterexample shapes (3a IS-X-but-fails / 3b fits-but-is-NOT-X), iteration chain to next attempted definition, north-star X header + initial response pinning. Work with fixture X = Justice (Republic Book I 327a–354c). Decide what persists across toggles and what live-only state (transcript cursor, search layer) evaporates.

## Answer

Board model locked over live grilling 2026-09-11/13, fixture X = Justice (Rep I 327a–354c):
- Roles: claimant is a formality for traceability/visuals; one defender at a time; anyone except Socrates may offer counterexamples or defend the active claim against them. Socrates is the questioner seat, human by default, rotating per board with tag-in/out by mutual agreement.
- Modes (renamed): LLM-as-Socrates (was Beginner) — facilitator IS Socrates: questions, votes, frequent unsolicited teaching callouts. LLM-as-participant (was Guided) — facilitator votes but is never Socrates; middle unsolicited. LLM-only-assists (was Open) — no vote, never Socrates, assistance only. Otherwise facilitator identical across modes. Mode chosen per board at creation (no default; YAGNI), changeable by room agreement.
- Board: X immutable per board (new X = new board); answerer's initial response pinned verbatim, always visible. Canonicals auto-pulled, immutable, cited. Claiming copies a canonical into claimed tagged with source, or authors an original. Exactly one active definition, front-center, counterexamples in its vicinity; revisions create new version nodes (v1→v2, never edit), history pannable toward the past (up/left).
- Counterexamples labeled 3a (IS-X-but-fails) / 3b (fits-but-is-NOT-X), each carrying stands/rebutted flippable by anyone. Refuted = standing counterexample(s) by majority vote: universal franchise (defender, Socrates, all participants, plus facilitator in Socrates/Participant modes); facilitator tallies, votes its own LLM assessment where enfranchised.
- Voting: ambient LLM tally of informal spoken/text votes plus explicit calls ("call it"); false-positive tallies tolerated, self-corrected, multitasked alongside listening. Live/verbal resolved against enrolled voiceprints (see 07); async votes are text records on the counterexample.
- Advancement: a lost vote cannot be bypassed within the mode — advance by persuading a vote-change or switching mode (the always-available hatch). Facilitator never unilaterally blocks.
- Toggle async/live: all records persist (transcript segments, canonicals, chain, statuses, active pointer, votes); only live-ephemeral evaporates (mic/VAD state, transcript cursor, partial hypotheses, search spinners). Canonicals cached per X, never re-pulled mid-dialogue.
- Follow-up split out: speaker enrollment/voiceprint calibration → 07 (revisits 05's post-hoc-only call). Non-definitional claims (e.g. empirical predictions) explicitly future, out of scope.
